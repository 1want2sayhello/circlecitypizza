## About Circle City Pizza

Circle City Pizza is a fictional pizzeria website designed and developed to demonstrate modern front-end development and responsive web design for small businesses. 

**Goal**: Create an inviting, visually distinctive online presence with responsive layouts, and a focus on showcasing the restaurant's menu.

## Key Features 🔑


**View Menu** - Browse a categorized selection of pizza, wings, sides, salads, and desserts with descriptions and pricing.

**Clean UI** - Navigate an intuitive, visually cohesive interface designed for a simplified user experience and highlight the restaurant's menu items.

**Responsive Design** - Enjoy a consistent, accessible browsing experience across desktop, mobile and tablet views.
